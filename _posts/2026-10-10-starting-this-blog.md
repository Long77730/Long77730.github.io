这是我整理个人网页和写作记录的起点。我希望这里既能放下简短的学习笔记，也能记录一个页面从想法到发布的过程。

## 为什么做这个博客？

做网页时，很多细节是在尝试和调整中弄明白的。把过程写下来，可以帮助我回顾思路，也方便以后继续完善作品。

我会在这里记录：

- HTML 结构与 CSS 样式练习
- 静态网页制作中遇到的问题和解决过程
- 值得反复查看的学习笔记与灵感

## 这个站点如何发布？

文章使用 Markdown 编写，放在 `_posts/` 目录中。GitHub Actions 会运行 Jekyll，把文章和页面生成静态 HTML，再由 GitHub Pages 发布。日常写作不需要在电脑上安装 Node.js 或 npm。

## 接下来

我会从小页面和具体练习开始，慢慢补充项目记录。每次更新都尽量留下清楚的上下文，让未来的自己也能看懂当时为什么这样做。
